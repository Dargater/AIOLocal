Before the first start

        

          OVMS is a separate, externally licensed server. It is required for local
          models; it is not bundled. The app auto-detects the usual install folders and reports the
          resolved path above.
        

        

          Install OpenVINO Model Server, then set ovms.exe in Settings. OpenVINO GenAI
          can also run models in-process without a server, but this build does not bundle that
          Python engine, so OVMS remains the default backend.

How to use REA

        
    
          
  1. Start REA. The app launches its own portable Node runtime and the REA MCP package from the app tools folder. Nothing global is installed.
    2. 
          
  2. Read the tool list. The left card shows every tool REA exposes and what it does. Tool names and argument schemas come from REA itself, so they can change between releases.
    3. 
          
  3. Call one tool. Pick a tool, enter its arguments as a JSON object, and press Call tool. Start with read-only inspection tools.
    4. 
          
  4. Work on copies. Point REA at a copy of the file or folder you are studying. Avoid running write or patch tools on original files.
    5. 
        

        
Example argument shape: {"path": "C:\\samples\\app.exe"}. The exact keys are listed in each tool's description. Everything runs locally; results are not sent anywhere.

How docking works

          

            On Windows the app creates a native host window and re-parents the GIMP window into it.
            If GIMP exposes no window within 25 seconds, it stays in its own window and the app says
            so — closing the dock never kills GIMP or discards unsaved work.
          

          
GIMP 3 is a GTK3 app; browsers cannot host native windows, so the dock is a real Win32 window beside the app.

        

      


      

        
Using the OpenVINO plugin

        
    
          
  1. Launch GIMP and open or create an image. The plugin appears under Layers → OpenVINO-AI-Plugins.
    2. 
          
  2. Choose a plugin. Pick Stable Diffusion (or Super-Resolution / Semantic Segmentation), then choose a model and device and press Load Models. The first load can take minutes while weights are prepared.
    3. 
          
  3. Generate or edit. Type a prompt and press Generate. For inpainting, make a selection, add a layer mask initialized from that selection, then choose an inpainting model.
    4. 
          
  4. Save your work. The plugin writes a new layer or image. Use File → Export As for PNG/JPEG; GIMP's .xcf project stays local.
    5. 
        

        
If the menu is missing, reinstall the plugin from Setup, confirm the path shown above, and restart GIMP. The plugin uses the private OpenVINO models folder in this app, not a system install.
